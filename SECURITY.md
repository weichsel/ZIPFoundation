# Security Policy

Please report suspected vulnerabilities in ZIPFoundation privately using
[GitHub's vulnerability reporting form](https://github.com/weichsel/ZIPFoundation/security/advisories/new).
Do not open a public issue or pull request for an undisclosed vulnerability.

Include the affected version, platform, potential impact, and steps to reproduce
the issue. A minimal code example and sample ZIP archive are especially helpful.
Reports from automated tools should include a reproducible example demonstrating
the security impact.

We will review reports and coordinate fixes and disclosure with the reporter.
Response and resolution times depend on severity, complexity, and maintainer
availability. Please coordinate public disclosure with us so users have time to
update. Confirmed vulnerabilities will be published as GitHub Security Advisories,
with credit to the reporter unless they prefer to remain anonymous.
